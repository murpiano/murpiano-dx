# Следы агентной разработки

Что считается следом и где его быть не должно. Не применяется к репозиториям, которые сами
являются инструментами для агентов (например, `murpiano-dx`).

## 1. Где проверять

Всё, что видит посетитель репозитория:

- отслеживаемые файлы и их содержимое;
- каждый коммит в опубликованных ветках и тегах: сообщение, трейлеры, автор, коммиттер;
- названия веток и тегов;
- pull request: название, описание, ветка;
- релизы: название и заметки;
- description и topics репозитория.

## 2. Файлы

Не отслеживаются и не встречаются в опубликованной истории:

`CLAUDE.md`, `CLAUDE.local.md`, `AGENTS.md`, `GEMINI.md`, `.claude/`, `.agents/`,
`.codex/`, `.cursor/`, `.cursorrules`, `.cursorignore`, `.windsurf/`, `.windsurfrules`,
`.clinerules`, `.roo/`, `.roomodes`, `.continue/`, `.aider*`, `.kiro/`, `.junie/`,
`.specstory/`, `.serena/`, `.superpowers/`, `.mcp.json`, `.github/copilot-instructions.md`,
`.github/instructions/`, `.github/prompts/`, `memory-bank/`, `docs/superpowers/`.

## 3. Текст

Нигде в зоне проверки нет упоминаний ассистентов, агентов, моделей и генерации: названий
ассистентов и вендоров, `Generated with`, `Generated by`, `AI-generated`, `as an AI`,
`Co-Authored-By` с ассистентом или ботом, эмодзи робота.

Исключение: упоминание, которое часть самого продукта (например, интеграция с API модели).
Такое подтверждает автор.

## 4. Автор

Все авторы и коммиттеры в опубликованной истории — владелец, одно имя и один email. Для
репозиториев murpiano: `murpiano <159007823+murpiano@users.noreply.github.com>`.

## 5. Сообщения и ветки

- Сообщения коммитов, названия PR и релизов без эмодзи и по конвенции репозитория. Если в
  репозитории нет своей, используется формат kysaro: `type(scope): Subject`, subject с
  заглавной буквы, без точки, заголовок до 72 символов.
- Ветки не начинаются с `claude/`, `copilot/`, `codex/`, `cursor/`, `devin/`, `ai/`,
  `agent/`.

## 6. Профилактика

- Файлы из раздела 2 перечислены в глобальном git ignore
  (`git config --global core.excludesfile`, по умолчанию `~/.config/git/ignore`).
- Автоматическая подпись коммитов и PR выключена во всех агентах, где она есть.

## 7. Что нельзя убрать

GitHub хранит `refs/pull/<n>/head` каждого PR с исходными коммитами. Удалить их может только
поддержка GitHub. Форки и чужие клоны тоже сохраняют старую историю.
