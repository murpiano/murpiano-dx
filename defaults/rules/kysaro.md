# [Kysaro](https://github.com/murpiano/kysaro) standard

Install [Kysaro](https://github.com/murpiano/kysaro) locally per project. Keep `.kysaro/settings/`, the `commit-msg` hook,
and the [Kysaro](https://github.com/murpiano/kysaro) workflow in that project. Preserve custom hooks and never overwrite
project-specific settings without approval.
