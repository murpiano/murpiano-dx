# Release standard

Use Semantic Versioning and `vX.Y.Z` tags. Keep experimental versions below `1.0.0`.
Release only after green CI. Release descriptions are written strictly in English.
Describe user-visible results, not only commit subjects: extract concrete points
from commit bodies, merge equivalent points, remove duplicates, and resolve
contradictory points in favor of the latest commit. Never include agent traces or
secrets.
