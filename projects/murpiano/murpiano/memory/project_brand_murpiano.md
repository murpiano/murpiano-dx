Бренд "murpiano" = личный бренд пользователя. Имя — слияние "пианино" + "мурлыкание" (кот/музыка), плюс код (программирование). Два направления: музыка (окончил муз школу, играет ~40 произведений на пианино, продолжает учить) и программирование (окончил курсы, хобби → цель стать специалистом).

Слоган на логотипах: "MUSIC & CODE".

**Why:** бренд объединяет оба увлечения пользователя в одном нике/визуале (кот+пианино+код).
**How to apply:** все материалы бренда (лого, сайт, тексты) должны отражать связку музыка+код, не только одно из двух.
